╔─────────────────────────────────────────────────────╗
│  SECTION 01 :: WHAT ARE OUTPUT STYLES?              │
╚─────────────────────────────────────────────────────╝

Output Styles are PERSONA TEMPLATES that change HOW Claude
responds — not what it knows, but how it communicates.

Each style is defined in a Markdown file (*.md) stored inside:

    .claude/output-styles/     <-- project-level
    ~/.claude/output-styles/   <-- global (user-level)

These files contain YAML frontmatter + plain-English instructions
that shape Claude's tone, format, and structure for every reply.

Think of them like "modes" or "themes" for the AI's voice.

╔─────────────────────────────────────────────────────╗
│  SECTION 02 :: HOW DO THEY WORK?                    │
╚─────────────────────────────────────────────────────╝

1. You invoke a style with:
   /output-style <name>

2. Claude Code reads the matching .md file from the
   output-styles directory.

3. The instructions in that file override Claude's
   default response behavior for the session.

4. The frontmatter field:
   keep-coding-instructions: true
   ...ensures technical accuracy is preserved even
   while the style transforms the format.

╔─────────────────────────────────────────────────────╗
│  SECTION 03 :: BUILT-IN STYLES (SYSTEM DEFAULT)     │
╚─────────────────────────────────────────────────────╝

These ship with Claude Code out of the box:

  [default]     Standard balanced responses
  [Proactive]   Executes immediately, minimal interruptions
  [Concise]     Terse, results-first, no preamble
  [Explanatory] Explains implementation choices + patterns
  [Learning]    Pauses to let YOU write code (hands-on)
